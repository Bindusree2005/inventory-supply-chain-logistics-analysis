# Inventory, Supply Chain & Logistics Analysis

## Project Overview
This project uses MySQL and Power BI to analyze inventory management, sales performance, purchasing operations, and shipment delivery performance. It demonstrates how SQL-based analysis and interactive dashboards can help businesses monitor stock availability, identify replenishment needs, and evaluate logistics performance.

## Business Objectives
- Monitor inventory levels and identify products below reorder thresholds.
- Analyze sales revenue and monthly sales trends.
- Evaluate purchase orders and supplier activity.
- Track shipment statuses and on-time delivery performance.
- Build an interactive dashboard to support data-driven operational decisions.

## Tools & Technologies
- MySQL and SQL
- Power BI Desktop
- DAX
- Power Query

## Database Design
The relational database contains eight tables:

1. Products
2. Suppliers
3. Warehouses
4. Inventory
5. Purchase Orders
6. Purchase Order Items
7. Shipments
8. Sales

SQL joins, aggregate functions, CASE statements, and data-quality checks were used to analyze the data.

## Key Performance Indicators
- **Total Sales Revenue:** ₹11,84,800
- **Total Inventory Value:** ₹32,81,630
- **Low-Stock Records:** 15
- **Units to Reorder:** 183
- **On-Time Delivery Rate:** 66.67%

These figures are calculated from the project's synthetic dataset and may depend on the selected filters or metric definitions.

## Key Findings
- September sales revenue was 23.86% higher than August in the sample dataset.
- Fifteen product–warehouse records were below their reorder thresholds.
- The calculated replenishment shortfall was 183 units.
- Eight of twelve delivered shipments arrived on time.
- Mumbai Main Warehouse had the highest inventory value among the five warehouses.

## Power BI Dashboard
The interactive dashboard includes:
- KPI cards for sales, inventory, stock shortages, and delivery performance.
- A monthly sales revenue line chart.
- An inventory value comparison by warehouse.
- A stock-status chart.
- A shipment-status donut chart.
- Slicers for warehouse, product category, and sales date.

## Business Recommendations
- Prioritize replenishment for products below their reorder levels.
- Review sales trends when planning inventory allocation.
- Investigate delayed shipments and monitor carrier performance.
- Regularly review warehouse inventory value and stock availability.

SQL querying, relational database design, data validation, business analysis, DAX measures, Power BI dashboard development, KPI reporting, and insight generation.
